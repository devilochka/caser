# КЕЙСЕР — готовая сборка для GitHub Pages

Скопируйте всё содержимое этой папки в корень репозитория с заменой старых файлов. Включите скрытые файлы: .nojekyll тоже нужен. Не загружайте сам ZIP.

В GitHub Desktop: Summary → Commit to main → Push origin. В GitHub: Settings → Pages → Deploy from a branch → main → / (root). Дождитесь зелёной сборки в Actions.

Сборка работает и в корне сайта, и в подпапке /caser/. Все последние изменения включены. Сохранения находятся в браузере, отдельно для каждого пользователя и адреса сайта. Виртуальные баланс и предметы.

Панель Chrome включается в настройках профиля. F11 — полный экран. Некоторые картинки предметов загружаются из Steam CDN.
